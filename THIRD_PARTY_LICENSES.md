# Third-party components

- [QQMusicApi / qqmusic-api-python 0.7.3](https://github.com/L-1124/QQMusicApi): GPL-3.0-or-later. The Windows package bundles this Python dependency. Its license text is in [LICENSE](LICENSE). The project uses read-only QR login, account, favorites, and playlist APIs. Music download APIs are not used.
- [TH911/NeteaseCloudMusicApi](https://github.com/TH911/NeteaseCloudMusicApi): MIT. Self-contained portable packages include the fixed source and production dependencies; their MIT license is retained in the runtime directory. Source installs can still prepare the helper locally. The helper listens only on `127.0.0.1` during export.
- [Node.js](https://nodejs.org/): the portable packages include the native Node executable and `NODE-LICENSE.txt`, including third-party notices. npm is not shipped.

The original NetEase Music Insight 1.0 source was published under MIT by rhr-jz; its notice is retained in [LICENSE_MIT_ORIGINAL](LICENSE_MIT_ORIGINAL). The 1.1 combined application is distributed under GPL-3.0-or-later to comply with its QQMusicApi dependency.
