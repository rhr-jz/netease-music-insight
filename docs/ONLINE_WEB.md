# Music Insight Online Web

Online Web 是 v3 的新增入口，与 Desktop、Local Web、CLI 共用现有 Core。当前代码提供可部署的服务器；仓库中没有假定一个已经运行的官方公网地址。

## 用户流程

打开部署者提供的 HTTPS 网址 → 阅读在线隐私说明 → 选择网易云、QQ 音乐或两个平台 → 对应 App 扫码并确认 → 点击开始整理 → 浏览 Dashboard 与音乐档案 → 选择 AI 方向 → 下载文件并复制 Prompt。

用户无需 Python、Node、EXE、API Key 或手动 Cookie。手机浏览器建议配合另一设备扫码，也可以保存二维码后尝试 App 识别；平台能否识别图片由对应 App 决定。

## 页面

- 首页与连接：品牌介绍、在线与本地区别、三种数据来源、明确处理数据的同意。
- 登录与进度：生成、等待、已扫码、确认、成功、过期、刷新、取消；后台 Worker 不阻塞请求线程。
- 我的音乐：收藏、歌曲、歌手、专辑、歌单、可用记录、Top Artists / Albums、来源与更新时间。
- 音乐档案：全部歌曲、喜欢、歌单详情、记录、搜索；每页最多 40 条，不一次创建数千 DOM。
- 跨平台：复用 `combined.py` 的保守匹配，显示共同录音、独有歌曲、歌手与歌单结构。
- AI 分析：唯一数据源为 `guidance.py` 的 13 个方向；缺少真实时间、歌单或双平台数据时隐藏对应方向。可查看、复制、下载完整 Prompt 与使用说明。
- 导出：JSON、Markdown、指南、独立 Prompt 和 ZIP。下载需要当前会话且文件必须存在于结果清单。
- 设置 / 隐私：深色、浅色、跟随系统；清缓存、重新整理、退出并清数据。

## 临时数据与恢复

浏览器保存的只有本应用的 HttpOnly Session Cookie，不保存平台凭据。刷新可以恢复同一会话的任务与结果；不使用浏览器 LocalStorage 保存 Token。SSE 传递状态快照，连接失败时回退轮询。

会话为绝对 TTL，默认 3600 秒；结果还受最后完成时间起计算的 RESULT_TTL 限制，默认 3600 秒。以两者中先到期者为准。TTL 到期会取消正在进行的任务，撤销下载并清除临时数据。退出立即撤销访问与凭据；正在进行的同步请求不能被 Python 线程强制中断，返回后完成目录清理。

容器重启后 Session 与 Job 不恢复，必须重新扫码。单平台重同步后，陈旧的联合结果和下载 ID 失效；需要重新执行“两平台”以生成一致的联合档案。

## 数据边界

在线版会由部署服务器临时处理凭据和音乐元数据，不能宣称“数据始终不离开电脑”。没有广告、遥测 SDK、数据库或自动 AI 上传。技术日志只记录固定阶段和错误类别，不记录 Cookie、QR URL、歌单或完整 JSON。服务器运营者和网络服务商的处理政策仍需单独了解。

Local Web 与 Desktop 保留本地运行能力，适合不愿让服务器处理音乐数据的用户。[隐私说明](../PRIVACY.md) · [部署](DEPLOYMENT.md)
