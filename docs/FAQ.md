# 常见问题

## 二维码过期或登录失败

二维码过期后按 Enter 刷新。确认使用网易云音乐 App 扫码，并在手机端点击确认。若仍失败，稍后重试；网易云未公开接口可能变化。

## 首次启动很慢

源码版会建立 Python 虚拟环境。程序还会下载本地接口代码并安装其依赖；Windows 在没有 Node.js 时会准备便携版本，macOS 需要预先安装 Node.js 18+。首次运行需要访问 Python 包索引、GitHub、Node.js 官网和 npm 仓库，后续运行会复用已下载的组件。

## 为什么播放记录少于我的真实听歌历史？

网易云服务端只允许接口返回有限范围的播放记录。这里不是账号完整终身播放流水，也不是逐次事件列表。

## 为什么有歌单或歌曲缺失？

私密歌单、下架歌曲、临时接口失败或登录过期都可能造成缺口。请查看 `music_summary.md` 和 JSON 的 `export_meta.issues`。程序会缓存成功的歌单，下次运行可继续；`--fresh` 可强制重新获取所有数据。

## 数据存在哪里？如何删除？

导出文件在 `output/用户名_UID/`，阶段性缓存位于 `.cache/UID/`。退出程序后直接删除这两个目录即可。详情见 [隐私说明](../PRIVACY.md)。

## 我需要安装 Git 或手动找 Cookie 吗？

不需要。源码版需要 Python；macOS 源码版还需要 Node.js 18+，Windows EXE 版不需要预装 Python 或 Node.js。登录只需手机扫码。

## macOS 提示无法打开启动脚本怎么办？

请确认仓库 ZIP 已完整解压，并双击带有 `.command` 后缀的 `一键运行.command`。如果脚本被意外移除了执行权限，可在仓库目录运行 `chmod +x 一键运行.command` 后重试。

## Edge 提示“检测到病毒”怎么办？

不要关闭安全软件或强行保留文件。先确认下载来自本项目 GitHub Release；尝试同一 Release 的目录版 ZIP，完整解压后运行。若仍被拦截，请使用源码版，并按照[下载与安全说明](../SECURITY.md)提交检测名称与文件 SHA-256，方便排查。
