# 常见问题

## Local Web 是云端网站吗？手机能访问吗？

不是。Local Web 在你的电脑上启动本地后端，只监听 `127.0.0.1` 的随机端口，并自动打开系统默认浏览器。它不会把音乐数据默认传到作者服务器。同一局域网内的手机无法直接访问这个地址；请在电脑打开网页，再用手机扫描电脑上的二维码。源码入口为 `python run_web.py`，桌面版可在“设置”中启动。

## AI 分析需要 API Key 吗？

不需要。Music Insight 整理数据并提供可独立复制的 Prompt；你自行选择支持文件上传的 AI。只有你主动上传导出文件时，该 AI 服务才会收到数据。[分析方向与证据边界](AI_ANALYSIS.md)。

## 二维码过期或登录失败

桌面 GUI 的二维码过期后点击“重新生成”；CLI 中网易云按 Enter 刷新，QQ 会自动尝试刷新。请用所选平台对应的 App 扫码并在手机端确认。若仍失败，稍后重试；平台未公开接口可能变化。

## 首次启动很慢

源码版会建立 Python 虚拟环境。网易云音乐还会下载本地接口代码并安装其依赖；Windows 在没有 Node.js 时会准备便携版本，macOS / Linux 的网易云导出需要预先安装 Node.js 18+。仅使用 QQ 音乐无需 Node.js。首次运行需要访问 Python 包索引；网易云还需访问 GitHub、Node.js 官网和 npm 仓库。后续运行会复用已下载的组件。

## 为什么播放记录少于我的真实听歌历史？

网易云服务端只允许接口返回有限范围的播放记录。这里不是账号完整终身播放流水，也不是逐次事件列表。

QQ 音乐播放历史目前没有通过真实账号验证的可靠接口，所以输出为空并明确标记不可用。收藏顺序不会被当成播放历史。

## 为什么有歌单或歌曲缺失？

私密歌单、下架歌曲、临时接口失败或登录过期都可能造成缺口。请查看 `music_summary.md` 和 JSON 的 `export_meta.issues`。程序会缓存成功的歌单，下次运行可继续；`--fresh` 可强制重新获取所有数据。

## 数据存在哪里？如何删除？

网易云导出文件在 `output/用户名_UID/`，QQ 在 `output/qq_music/用户名_UID/`；阶段性缓存分别在 `.cache/UID/` 与 `.cache/qq_music/UID/`。Desktop 和 Local Web 的“导出”页会显示当前文件；Web 版可直接下载。详情见 [隐私说明](../PRIVACY.md)。

## 我需要安装 Git 或手动找 Cookie 吗？

不需要。源码版需要 Python；macOS / Linux 导出网易云还需要 Node.js 18+，Windows EXE 版不需要预装 Python 或 Node.js。登录只需手机扫码。

## macOS 提示无法打开启动脚本怎么办？

请确认仓库 ZIP 已完整解压，并双击带有 `.command` 后缀的 `一键运行.command`。如果脚本被意外移除了执行权限，可在仓库目录运行 `chmod +x 一键运行.command` 后重试。

## Edge 提示“检测到病毒”怎么办？

不要关闭安全软件或强行保留文件。先确认下载来自本项目 GitHub Release；v1.1.0 起提供目录版 ZIP，请完整解压后运行。若仍被拦截，请使用源码版，并按照[下载与安全说明](../SECURITY.md)提交检测名称与文件 SHA-256，方便排查。


## Online Web 需要下载 EXE 吗？

部署后的 Online Web 不需要安装。当前仓库提供可部署代码，实际使用需部署者提供 HTTPS 地址。GitHub Pages 不能运行扫码后端；JSON 导入浏览器预览只处理已有文件。

## 在线版会收到我的数据吗？

会。为了扫码和整理，部署服务器临时处理平台凭据与音乐元数据；不自动上传给 AI，不建立长期账号档案，默认会话/结果最多一小时。退出可提前清理。希望数据留在自己电脑时，请选择 Desktop / Local Web。

## 刷新、关闭和过期有什么区别？

同一 Cookie 的短暂刷新可以恢复任务；关闭页面不会立即删除任务。退出或 TTL 到期会撤销会话、取消任务并清理临时结果。下载好的文件仍保存在你自己的设备。服务器重启需要重新扫码。

## 为什么成长轨迹或年度总结没有显示？

在线版会隐藏缺少可靠时间等必要数据的方向。收藏顺序不能当作收藏日期；QQ 收藏歌单的排序时间也不保证是首次收藏时间。
