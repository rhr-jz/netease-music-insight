# AI 分析中心

Music Insight 负责把个人音乐数据整理成可核对的 JSON、摘要和独立 Prompt；它不接入收费 AI API，也不要求填写 API Key。你可以选择任何支持文件上传的 AI。上传前请自行确认所选服务的隐私规则。

## 使用方法

1. 在 Desktop 或 Local Web 中完成一次数据整理，打开“AI 分析”。
2. 选择一个感兴趣的方向，阅读完整 Prompt，并点击“复制 Prompt”。
3. 在“导出”页找到 `music_for_ai.json`；联合分析使用 `music_for_ai_combined.json`。
4. 打开 ChatGPT、Claude、Gemini 或其他支持文件上传的 AI，上传数据文件并粘贴 Prompt。
5. 要求 AI 用具体歌曲、歌手或歌单作为证据，并说明无法从数据推断的部分。

每个 Prompt 都可单独使用，无需按顺序执行。文件版指南仍写入 `AI_ANALYSIS_GUIDE.md`，单独主题保存在导出目录的 `prompts/`。

## 分析方向

| 方向 | 可探索的问题 |
| --- | --- |
| 音乐全景画像 | 我的收藏和兴趣呈现怎样的整体结构？ |
| 真实音乐审美 | 我真正喜欢哪些声音、旋律和氛围？ |
| 核心歌手 | 哪些音乐人对我最重要？ |
| 听歌习惯 | 收藏、歌单与可获取的播放记录有什么关系？ |
| 音乐成长轨迹 | 有可靠时间的数据中，兴趣怎样变化？ |
| 我的音乐地图 | 如何从熟悉的音乐走向邻近领域？ |
| 审美盲区 | 哪些音乐离现有口味只有一步？ |
| 同龄人音乐谈资 | 哪些音乐人、作品和文化值得了解？ |
| 系统听歌计划 | 怎样轻松地拓展音乐品味？ |
| 歌单整理 | 哪些歌单适合保留、合并或拆分？ |
| 情绪与音乐 | 不同心情和场景下有哪些可用的音乐？ |
| 年度音乐总结 | 有可靠年份依据时，如何回顾音乐记忆？ |
| 跨平台比较 | 网易云与 QQ 音乐的数据有哪些相同与差异？仅联合数据可用。 |

## 证据边界

- 网易云播放历史取决于平台当前返回范围，不能当成终身完整记录。
- QQ 音乐没有已验证的可靠完整播放历史。缺失不代表没有反复听歌。
- 收藏时间、歌单创建时间与收藏排序时间有不同含义。仅使用实际返回的时间；缺失时不能编造阶段或年度结论。
- 歌曲元数据通常不能证实旋律、歌词或情绪。若 AI 没有试听依据，应要求它注明推测或待核实。
- 外部推荐、当下流行趋势和音乐文化话题具有时效性；请让具备联网能力的 AI 标注来源和日期。

格式和缺失标记见 [DATA_FORMAT.md](DATA_FORMAT.md)。
